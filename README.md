# Business Tools Suite

Professional business productivity tools built using HTML, CSS, and JavaScript.

## Included Tools

### 1. Quotation Builder
Generate professional quotations with:
- Dynamic pricing
- Client management
- PDF export
- Print-ready layouts

### 2. Invoice Generator
Create professional invoices with:
- Payment calculations
- Invoice status handling
- PDF generation
- Business branding

### 3. Brochure Builder
Design modern brochures with:
- Dynamic layouts
- Branding support
- Multi-page previews
- Export functionality
